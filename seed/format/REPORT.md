## API
- `validate(doc, catalogue)` returns `{ok, errors, warnings, layers_run}`. Each issue has the shape `{layer, code, node, path (JSON Pointer), message}`.
  - It never throws. Internal bugs come back as `INTERNAL_ERROR`.
  - It takes about 0.13 ms per call on RF-1.
  - The layers are gated: L2 runs only if L1 is clean, and L3 only if L1 and L2 are clean. Scorers must read `layers_run`.
- `checkRubric(doc, rubric, {seed?})` returns `{passed, total, ok, results:[{check, pass, detail, spec}]}`.
- `canonicalize`, `canonicalJson` and `canonicalEqual` give a canonical form: sorted keys and whitespace-normalised references, with no default injection.
- `parseFlowText(text, "yaml"|"json")` parses safely (YAML 1.2 core, duplicate keys rejected).

## CLI
```
npx tsx src/cli.ts validate  <file> [--json] [--catalogue <file>]
npx tsx src/cli.ts rubric    <flow> <rubric.json> [--seed <file>] [--json]
npx tsx src/cli.ts canonical <file> [--pretty]
```
Exit codes: 0 means ok, 1 means errors or failed checks, 2 means a usage or I/O problem.
