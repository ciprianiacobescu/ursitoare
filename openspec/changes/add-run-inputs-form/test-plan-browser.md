# Browser tests (mocked answers, no sign-in, no fixtures from the stack)

`e2e/test_m6b_run_inputs.py`: five test functions (the last parametrized, seven runs in all), each with `@pytest.mark.milestone("M6b")` and `@pytest.mark.l4("C-…")` (the id L4 derives for its scenario). They use the `page` fixture only and import `assert_accessible`, `watch_csp` from `conftest`. Locators are by role and name with `exact=True`; no sleep; a hit count is read only after an `expect` on text that only that reply renders.

Helpers inside the file (all answers `application/json`, status 200, through `page.route`):
- `ME` is `{ user: { id: "user-1", displayName: "Alice Example", email: null }, tenant: { id: "tenant-1", name: "E2E tenant", reviewProfile: "solo" }, capabilities: [read_self, read_flow, read_run, test_flow, dry_run_flow], csrfToken: "t" + "A" * 42 }`. `HASH` is `"sha256:" + "a" * 64`, `ENC` the same with `%3A`. `VERSION` is `{ flowId: "demo-pay", number: 1, hash: HASH, state: "validated", surface: "yaml", author: "user-1", requestedBy: null, createdAt: "2026-11-06T10:00:00.000000Z", validatedAt: "2026-11-06T10:00:01.000000Z", validationOk: true }`; `FLOW` is `{ flowId: "demo-pay", ownerTeam: "finance", createdBy: "user-1", createdAt: "2026-11-06T10:00:00.000000Z", versionCount: 1, latest: VERSION }`; `RESULT` is `{ ok: true, errors: [], warnings: [], layers_run: ["L1", "L2", "L3"] }`; `RUN` is a queued mock-run `RunView` (the 15 keys of `parseRunView`: `id` `run_1`, `flowId`, `flowHash` HASH, `mode` `mock`, `trigger` `test`, `state` `queued`, `ownerTeam` `finance`, `principal` `{ userId: "user-1", kind: "human" }`, `createdAt` `2026-11-06T10:00:02.000000Z`, and `null` for `terminalNode`, `error`, `inputRef`, `outputRef`, `startedAt`, `endedAt`).
