## Context

U33 walks a stored version over an injected `ToolInvoker`, U34 journals every effect, U36 reads runs. This change adds the mock side: the check of the mocks, an invoker that answers only from them and the endpoint that starts a mock run (the offline command is `add-flow-test-cli`). A mock run reaches no tool: its only invoker is the mock one (`testRunInvokers` refuses every other mode) and `interpreter` carries no egress.

## Decisions

1. **`checkMocks`** (`src/interpreter/mocks.ts`, no I/O). `mocks` must be a plain object, else one problem `{ nodeId: "", index: null, reason: "shape", detail: "mocks must be an object" }`. Reachable nodes: breadth-first from `flow.start` over the ids of `successorFields(node)` that are own keys of `flow.nodes`; the reachable blocks are those of kind `block`. Per key of `mocks` (`Object.keys`, so `__proto__` from `JSON.parse` is a key): not an own key of `flow.nodes` is `unknown_node`; a node that is not a block is `not_a_block`; a value that is not an array is `shape` with `index` null; else each entry `i` must be a plain object with exactly one own key, `output` (any JSON) or `error` (an object of exactly `code`, matching `^[A-Za-z][A-Za-z0-9_.-]{0,63}$`, and `message`, a string of 1 to 500 characters), else `shape` at `i`. An `output` is checked against `catalogue.block(uses)?.output` by one module-level `Ajv2020` with U33's options (`{ allErrors: false, strict: false, validateFormats: false }`); a failure is `schema` with `detail` `<instancePath or "/"> <keyword>` (never a value), and an uncompilable schema is `schema` with `detail` `output schema cannot be compiled`; a block the catalogue lacks is not schema-checked (`startRun` refuses it as `block_missing`). A reachable block whose list is absent or empty is `missing` (`index` null). Problems are ordered by `nodeId` (UTF-16 order) then `index` (`null` first) and cut at 50. `details`: `no mock entry`, `no such node`, `node is not a block`, `entries must be an array`, `entry must be {output} or {error: {code, message}}`. With no problem the result is `{ mocks: structuredClone(input), problems: [] }`, else `{ mocks: null, problems }`.
2. **`createMockInvoker`.** `invoke(call, ctx)`: the list is `mocks[call.nodeId]` when `Object.hasOwn`, else `mock_missing`; the entry is index `ctx.attempt - 1`, past the end `mock_exhausted`; an `error` entry is `mock_error` with `details.mockCode` the entry's code; an `output` entry resolves `{ output: structuredClone(output) }`. Every failure is `InterpreterError("INTERPRETER_TOOL_FAILED", "mock " + reason, call.nodeId, details)`: the entry's `message` is never copied, so the run holds only U33's fixed `INTERPRETER_TOOL_FAILED` and the node. D18 gives `attempt` 1, so M4 uses index 0.
3. **`testRunInvokers(store)`** returns `(mode, run) => Promise<ToolInvoker>`. `invokerFor` gets no tenant, so for `mock` it resolves an invoker that on its first `invoke` reads `store.getPayload(ctx.tenant, run.mocksRef)` and builds `createMockInvoker` from it, kept by that invoker; `mocksRef` null, no payload or a payload that is not a plain object is `INTERPRETER_TOOL_FAILED` with `details.reason` `mocks_unavailable`. `live` and `stub` reject `InterpreterError("INTERPRETER_NO_INVOKER", ...)`.
4. **`registryVersionLoader(pool)`** is `(ctx, flowId, hash) => withTenantTx(pool, ctx, ...)`: `getVersion` and `flowOwnerTeam`; `null` when either is `null` (`getVersion` answers `null` for a malformed hash); else `{ flowId, hash, state: version.state, ownerTeam, flow: version.canonical as Flow }`.
5. **The route.** `defineRoute` `POST /api/v1/flows/:flowId/versions/:hash/test`, `auth` session, action `test_flow`, `schema` `params` (`flowId` `FLOW_ID_PATTERN`, `hash` `^sha256:[0-9a-f]{64}$`, no extra), `headers` `IDEMPOTENCY_HEADER_SCHEMA`, `body` `{ input: object, mocks: object }` both required, `additionalProperties: false`, response 202 `{ run: RUN_VIEW_SCHEMA }`; `errors` `IDEMPOTENCY_IN_PROGRESS`, `IDEMPOTENCY_KEY_REUSED`, `OPERATION_REFUSED`, `RUNS_UNAVAILABLE`, `TEST_MOCK_INVALID`, `TEST_MOCK_MISSING`, `VALIDATION_FAILED` (12 with the implied ones). `context(request)` throws `RUNS_UNAVAILABLE` (503, "Runs are unavailable") when `deps.pool` is `null`, `deps.interpreter` is `null`, or `deps.interpreter.durable` is `null` (a run that cannot be enqueued would never start), and `AUTHZ_UNAVAILABLE` without tenant or principal; the `resource` loader calls it, then `flowOwnerTeam` (`null`: the PEP's 404), else `{ type: "Flow", id: flowId, tenantId, attrs: { owner_team: entityRef("Team", scopedId(tenantId, team)), reviewed: false } }`. **Handler order:** `loadVersion` (`null`: 404 `NOT_FOUND`); `catalogueFor`; `checkMocks`; problems: all `missing` is `TEST_MOCK_MISSING` 422 with `details.nodes` (the node ids), else `TEST_MOCK_INVALID` 422 with `details.problems`; then the run id: without a key `deps.ids.next("run")`, with `Idempotency-Key` `withIdempotency(ctx, principal, key, requestDigestOf({ method, route, params, query, body }), fn)` where `fn` returns `{ status: 202, body: { runId: deps.ids.next("run") } }` and a replay sets `Idempotent-Replayed: true`; then `startRun(interpreter, tenant, { flowId, hash, mode: "mock", input, mocks, principal: { userId, kind }, actorChain: [userId], runId })`, run on first call and replay alike (U33 answers the stored run for a known id); answer 202 `{ run: toRunView(run) }`. `startRun` errors map: `INTERPRETER_VERSION_NOT_FOUND` 404 `NOT_FOUND`; `INTERPRETER_VERSION_NOT_RUNNABLE` 422 `OPERATION_REFUSED` `{ reason: "version_not_runnable", cause: <its details.reason>, blocks?: <its details.blocks> }`; `INTERPRETER_KIND_UNSUPPORTED` 422 `OPERATION_REFUSED` `{ reason: "kind_unsupported", kinds }`; `INTERPRETER_INPUT_INVALID` 400 `VALIDATION_FAILED` `{ fields: [{ field: "body/input", message: "must satisfy the flow inputs (" + path + " " + keyword + ")" }] }`; `INTERPRETER_UNBOUND` 503 `RUNS_UNAVAILABLE`; a `RunDataError` is 400 `VALIDATION_FAILED` `{ fields: [{ field: "body", message: "must be plain JSON of at most 1 MiB" }] }`; anything else is not mapped (500).
6. **Policy** `src/interpreter/policy/flow-testing.cedar`: `@id("interpreter-test-flow-author-owner-team") permit (principal in Role::"author", action == Action::"test_flow", resource is Flow) when { principal in resource.owner_team };` and `@id("interpreter-test-flow-capability") permit (principal in Role::"author", action == Action::"test_flow", resource is Tenant);` (the second feeds capabilities).
7. **`main.ts`.** Inside U30's launch condition and before its `launchDurable` call: `base = { store: createRunStore(pool), durable: null, loadVersion: registryVersionLoader(pool), catalogueFor: (ctx) => loadRegistryCatalogue(pool, ctx), invokerFor: testRunInvokers(store), effects: createEffectIntents(pool), clock: systemClock, ids: systemIds }`, then `(deps.registerRunWorkflow ?? registerRunWorkflow)()` and `(deps.bindInterpreter ?? bindInterpreter)(base)`, because DBOS recovers pending runs inside `launchDurable` and the workflow throws `INTERPRETER_UNBOUND` when nothing is bound. U30 calls `launchDurable` after the routes that need no runtime and before the listener binds; the routes that take the launched runtime, U36's `registerRunRoutes` and this change's, register after it and before the listener. So, directly after U36's `registerRunRoutes(...)`: `registerTestRunRoutes(server, { pool, clock: systemClock, ids: systemIds, interpreter })` with `interpreter` `{ ...base, durable }` when the runtime was launched, else `null` (no database, role `api` or `sandbox`, or no `database.app`). The registration runs in every case so the route table and `docs/api/openapi.json` hold the route.

## Failure cases

Bad body or path: 400 (Fastify's default 1 MiB `bodyLimit`). No pool, no interpreter, `interpreter.durable` `null`, or `enqueue` rejecting: 503 `RUNS_UNAVAILABLE` (error text dropped); `startRun` has already stored the run, so it is left `failed` (a refusal before `startRun` stores none); a retry with the same `Idempotency-Key` replays that failed run, so retry with a new key. A flow, version or tenant not visible: 404. A `draft` version, unsupported kind or missing block: 422 `OPERATION_REFUSED`. A mock problem: 422, no run. A key reused with another body: 422; in progress: 409. A crash after the key claim: the retry replays the stored `runId`. A mock error entry or an exhausted list fails the run at its node with `INTERPRETER_TOOL_FAILED`. A store fault: 500 `INTERNAL`.

## Security

1. Session and CSRF; `test_flow` on the Flow (owner team, authors); the second policy only feeds capabilities. A same-tenant stranger is 403, another tenant's flow 404.
2. No table. Runs, payloads and intents go through U31 and U34 under forced RLS in `withTenantTx` of the session's tenant.
3. The body is schema-checked, then `checkMocks` bounds what reaches the store (50 problems, no values echoed, `Object.hasOwn`, `__proto__` a plain key). Mock data is customer data, stored as payloads, never logged.
4. No secret is read; a mock `message` never reaches a run, log or response.
5. Abuse: a real tool call (no non-mock invoker exists), a prototype key, an oversized mock list, a key replayed with another body, another team's or tenant's flow, a draft version.
