# Browser tests (no sign-in, no fixtures from the stack)

`e2e/test_m6b_foundation.py`, three tests, each with `@pytest.mark.milestone("M6b")` and `@pytest.mark.l4("C-…")` (the id L4 derives for its scenario). They use the `page` fixture and the stack's `base_url`; imports: `from conftest import assert_accessible, assert_layout, watch_csp`. Locators by role, no sleep. `watch_csp(page)` is called before the first `goto`.

| test | scenario | steps | observable result |
|---|---|---|---|
| `test_signed_out_pages_are_styled_clean_and_accessible`, parametrized over `"/"` and `"/sign-in"` | "Signed-out pages are styled, clean and accessible" | `set_viewport_size(1366, 860)`; `watch_csp`; `goto(path)`; the `h1` is visible | `assert_layout(page, max_banner_px=300)` passes; the `h1` computed `font-size` (`parseFloat(getComputedStyle(el).fontSize)`) is at least 24; `assert_accessible(page)` passes; the `watch_csp` list equals `[]`. Measured: banner 97 px (`/`) and 55 px (`/sign-in`), `h1` 24 px |
| `test_watch_csp_reports_a_violation` | "watch_csp sees a violation and assert_layout reports numbers" | `watch_csp`; `page.route("**/csp-probe", …)` fulfils status 200, `text/html`, the header `Content-Security-Policy: default-src 'self'; style-src 'self'` and the body `<!doctype html><title>probe</title><style>p { margin: 0 }</style><header>probe</header><p>x</p>`; `goto("/csp-probe")`; wait for `load` | one entry of the list starts `Content Security Policy violation: style-src` (measured: `Content Security Policy violation: style-src-elem inline`, beside Chrome's message "Applying inline style violates the following Content Security Policy directive 'style-src 'self''…") |
| `test_assert_layout_reports_the_numbers` | the same | `watch_csp`; `set_viewport_size(1000, 700)`; `set_content` of `<header style="height:100px">h</header><div style="width:1500px">w</div>`; then of `<header style="height:100px">h</header>` | the first call (default 72) raises `AssertionError` whose text contains `banner 100px is taller than 72px` and `scrollWidth 1500 exceeds innerWidth 1000`; for the second content `assert_layout(page, max_banner_px=100)` passes and `max_banner_px=99` raises an `AssertionError` whose text equals `layout: banner 100px is taller than 99px`; the `watch_csp` list equals `[]` at the end |

All four runs passed against the scratch build and against main's live stack (green on arrival there).
