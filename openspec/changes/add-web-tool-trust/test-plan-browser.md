# Browser tests

`e2e/test_m8_tool_trust.py` holds `test_register_with_a_trusted_result` (`C-f52c8d49`), `test_replace_keeps_the_stored_trust` (`C-3a1c08af`) and `test_replace_drops_the_retry_flag_on_an_effect_change` (`C-08abe836`); `e2e/test_m8_tool_trust_review.py` holds `test_tool_settings_trust_discover_and_changes` (`C-c7bb4abe`). Each is `@pytest.mark.milestone("M8")` and `@pytest.mark.l4(...)`, takes only `page`, signs nobody in and mocks every answer with `page.route`. Helpers are copied from `e2e/test_m7_tool_registration.py` (`ME`, `EMPTY`, `IO`, `rec`, `detail`, `answer(page, path, *replies, method="GET")`, `start`) and `e2e/test_m7_tool_review.py` (`DP`, `mcp`, `T`, `S`, `DET`). `ME` holds `register_tool_server`, which the registration page and the tool servers page need. `start(page)` calls `watch_csp(page)` before the first `goto`, sets 1366x860 and answers `me` and `people`; `checked(page)` is `assert_layout(page)` then `assert_accessible(page)`; each test ends with `assert csp == []`. Locators use role and name with `exact=True`; a hit count follows an `expect` on content only that reply renders. `WARNING` is `TRUST_WARNING`; `eff(n)`, `dc(n)`, `trusted(n)`, `ack(n)` are the comboboxes "Effect of n", "Data class of n" and the checkboxes "Result of n is trusted", "I accept the warning for n".

## Register (`C-f52c8d49`)

`LEDGER` is `rec("ledger", "http_openapi", "https://tools.fake.test")` (also used below); the preview answers `{"version": "3.0", "basePath": "/v1", "operations": [op("createPayment", "POST", "/payments"), op("listVendors", "GET", "/vendors"), op("exportVendors", "HEAD", "/export", "method_unsupported")]}` with `op(i, m, p, x=None)` is `{"operationId": i, "method": m, "path": p, "name": None, "excluded": x}`; `posts` (POST `tool-registrations/openapi`) answers `(201, LEDGER)`; `tool-servers/ledger` `(200, detail(LEDGER))`; `tool-servers` and `credentials` `EMPTY`; `DOCJ` is `{"openapi": "3.0.3", "paths": {}}`.

## Replace (`C-3a1c08af`, `C-08abe836`)

`CP` and `LV` are surface tools `{"name", "effect", "input": IO, "output": IO, "call": {"kind": "http", "method", "path", "params": [], "body": False}, ...}`: `create_payment` (`pay`, `POST /v1/payments`, `untrusted_result` False, `unsafe_to_retry` False, `data_class` "private") and `list_vendors` (`read`, `GET /v1/vendors`, `unsafe_to_retry` False). `LED` is `{**detail(LEDGER), "state": "approved", "approvedDigest": "sha256:" + "d" * 64, "tools": TL, "approvedSurface": {"tools": [CP, LV]}}` with `TL` the `{"name", "effect", "ref": "ledger.<name>@1"}` of the two tools. `tool-servers/ledger` (GET) answers `(200, LED)`, `(200, {**LED, "state": "drifted"})`; `tool-servers/ledger/openapi` (PUT; `puts`) answers `(200, {**LEDGER, "state": "drifted"})`; the preview answers the operations `createPayment` (`POST /payments`, name `create_payment`) and `listVendors` (`GET /vendors`, name `list_vendors`), not excluded, `basePath` `/v1`. Both tests: `goto("/admin/tool-servers?server=ledger")`, click "Replace document" in the region "Change registration", fill "OpenAPI document (JSON)" `json.dumps(DOCJ)`, click "Preview operations" in the form "Replace document".
