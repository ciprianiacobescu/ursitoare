# Browser tests (mocked `/api/v1/me`, no sign-in, no fixtures from the stack)

`e2e/test_m6b_shell.py`: six test functions, each with `@pytest.mark.milestone("M6b")` and `@pytest.mark.l4("C-…")` (the id L4 derives for its scenario). They use the `page` fixture; imports `from conftest import assert_accessible, assert_layout, watch_csp`. Locators are by role and name with `exact=True`; no sleep.

Helpers inside the file:
- `mock_me(page, name="Carol Example", tenant="E2E tenant", caps=CAROL, status=200)`: `page.route("**/api/v1/me", …)` fulfils `status` with `application/json` and `{"user": {"id": "user-1", "displayName": name, "email": null}, "tenant": {"id": "tenant-1", "name": tenant, "reviewProfile": "solo"}, "capabilities": caps, "csrfToken": "t" + "A" * 42}`; for `status=401` the body is `{"code": "SESSION_ENDED"}` (as `test_l4_c_e3de8f9e.py`).
- `CAROL` = `read_self`, `manage_users_roles`, `read_audit`, `register_tool_server`, `deploy_policy`, `read_flow`, `read_run`; `ALICE` = `read_self`, `read_flow`, `read_run`.
- `open_as(page, width, height, path="/", **mock)`: `set_viewport_size`, then `watch_csp(page)` (before the first `goto`), `mock_me`, `goto(path)`; it returns the live CSP list. `nav` is `page.get_by_role("navigation", name="Main", exact=True)`.
