## ADDED Requirements

### Requirement: An adapter surface carries one call per tool and is checked per adapter
A surface tool SHALL carry exactly one of M6's `http` or a `call`. `checkAdapterSurface(adapter, surface)` SHALL answer `checkSurface(surface)` for `fixture`. For the other adapters it SHALL accept a plain object `{ tools }` of 1 to 100 tools and refuse the rest with `TOOLS_INVALID` and `details` `{ field, reason }` (as `checkSurface` does: not an object `tools`, `not_object`; another key `surface`, `unknown_property`; `tools` not an array `tools`, `not_array`; 0 or over 100 tools `tools`, `size`), checking each tool in this order: `http` present (`tools/<i>/http`, `unknown_property`); another unknown key (`tools/<i>`, `unknown_property`); `name` `^[a-z][a-z0-9_]{0,63}$` (`bad_value`) and unique (`duplicate`); `call` an object (`not_object`) without unknown members (`unknown_property`) whose `kind` is `ADAPTER_CALL_KINDS[adapter]` (`kind_mismatch`); the kind's members; the block part through `normalizeBlockImport` as `checkSurface` does; then the rules that read `input` or `output`, first for `http_openapi` and `mcp` that no `pattern` or `patternProperties` member remains in a schema object of `input` or `output`, walking only these schema positions: the root, the values of `properties`, `$defs`, `definitions` and `dependentSchemas`, and `items`, `prefixItems`, `allOf`, `anyOf`, `oneOf`, `not`, `if`, `then`, `else`, `contains`, `additionalProperties`, `propertyNames`, `unevaluatedItems` and `unevaluatedProperties` (the data of `enum`, `const`, `default`, `examples`, of `x-*` and of any unknown keyword is never walked, and a property named `pattern` under `properties` is not one; `tools/<i>/input` or `tools/<i>/output`, `pattern`: a backstop for U53 and U54, which drop them, because a server-supplied pattern can make the validator take exponential time). **http:** `method` one of the five, `path` as M6's `badPath` and without `?` (`bad_value`); every `{name}` a whole segment naming a `params` entry `in: "path"` and the reverse (`placeholder`, field `.../call/path`); `in` `path` or `query` (`bad_value`); `body` true only for POST, PUT and PATCH (`body_method`); every param a property of `input.properties` (`param_unknown`) of `type` `string` or `integer` for a path param and also `number` or `boolean` for a query param (`param_type`); with `body` false every `input` property a param and no `patternProperties` (`property_unsent`). **mcp:** `endpoint`, `name` and `protocolVersion` match the patterns and values of `McpCallSpec` and `output` is `structured` or `text` (each `bad_value`); `hints`, when present, an object (`tools/<i>/call/hints`, `not_object`) whose only members are `readOnly`, `destructive` and `idempotent` (`unknown_property`), each a boolean (`bad_value`); `text` only when the tool's `output` deep-equals `MCP_TEXT_OUTPUT_SCHEMA` (`text_output`). **code:** `hints` is not a member (`tools/<i>/call/hints`, `unknown_property`, as for `http`); `source` of 1 to `MAX_CODE_SOURCE_CHARS` characters with no U+0000 and no lone surrogate (`bad_value`; `jsonb` cannot store them), `effect` `read` (`tools/<i>/effect`, `effect_not_read`), `untrusted_result` exactly `false` (`tools/<i>/untrusted_result`, `untrusted_result`). Last, the canonical JSON of the surface SHALL be at most `MAX_SURFACE_CHARS` characters (`surface`, `size`).

### Requirement: The surface digest covers the call and every M6 vector holds
`surfaceDigest` SHALL emit a tool's `http` only when it has one and its `call` only when it has one: http `{ kind, method, path, params, body }` with `params` in their order, mcp `{ kind, endpoint, name, protocolVersion, output }` plus `hints` (the members present) only when present, code `{ kind, source }`; member order in a call is free. `toolBlock`, `toolHash` and `surfaceRefs` SHALL stay as they are, so a call is not part of a block's content hash.

### Requirement: toolNameOf maps an external tool name to a tool name
`toolNameOf(external)` SHALL insert `_` between an ASCII lower-case letter or digit and a following ASCII upper-case letter, lower-case the text, replace each character outside `[a-z0-9_]` by `_`, collapse runs of `_`, trim `_` at both ends, prefix `t_` when the result does not start with a letter, cut it to 64 characters, and answer null for an empty result.

### Requirement: registerAdapterServerTx registers an adapter server pending
`registerAdapterServerTx(tx, ctx, input, actor, opts)` SHALL, in this order, `assertTenant`, check the id as `registerToolServerTx` does, refuse `fixture` and any other adapter (`adapter`, `bad_value`), check the origin (`http_openapi` and `mcp` through `validateOrigin(origin, { local })`, the returned origin stored; `code_block` only `CODE_BLOCK_ORIGIN` with `local` false: `origin`, `code_block`), require a surface for every adapter but `mcp` (`surface`, `required`) and check a given one with `checkAdapterSurface`; then store the server `pending`, the surface row when there is one and the event `tools.server_registered` `{ adapter, origin }`, and answer the record as M6 does (`TOOLS_EXISTS` for a taken id). A surfaceless `mcp` record has `pendingDigest` null and `tools` `[]`. A refusal writes nothing.

#### Scenario: Registering each adapter, and each refusal
- **WHEN** `registerAdapterServerTx` runs on rows G1 to G3 and F1 to F5 of `test-plan.md` § Store rows
- **THEN** G1 to G3 answer their records and events and each refusal throws the code and `details` of its row (F5 `TOOLS_EXISTS`) and leaves 0 new rows in `tool_server`, `tool_surface` and the audit log

### Requirement: submitAdapterSurfaceTx follows the submit rules, and the newest surface wins a tie
`submitAdapterSurfaceTx(tx, ctx, serverId, surface, actor, opts)` and `submitSurface` SHALL share one locked submit: the server row `FOR UPDATE`, an unknown server `TOOLS_NOT_FOUND`, the adapter rule, the surface check for the server's adapter, then M6's rules (the approved digest or the newest unapproved digest again: the record unchanged; another stored digest: `TOOLS_REFUSED` `surface_known`; a new digest: stored with `submitted_at` the later of the clock and the newest surface's `submitted_at` plus one microsecond, an `approved` server set `drifted`, the event `tools.surface_submitted` `{ digest, drift }`). So a new digest that sorts below the newest one, submitted at the same instant, SHALL be the newest surface, show as `pendingDigest` and be approvable. `submitAdapterSurfaceTx` on a `fixture` server SHALL throw `TOOLS_REFUSED` `{ reason: "adapter_mismatch" }`; `submitSurface` on any other server SHALL throw the same, after its own `checkSurface` as on main. The first surface of a surfaceless `mcp` server has `drift` false. A refusal writes nothing.

### Requirement: The directory binds a call tool with its call and no http
For an approved tool whose surface tool has a `call`, `createToolDirectory(pool).resolve` SHALL answer the binding with `call` (a copy) and no own `http`; for an `http` tool it SHALL answer `http` and no own `call`, so every M6 binding deep-equals as before.
