## MODIFIED Requirements

### Requirement: Taint uses the shared algebra
L3 SHALL take every taint decision from `analyzeTaint` and `flowCapabilities`: an `untrusted` reference into a non-read block or an effectful agent is an error, `extracted` data is not, and `code` output keeps its input's taint; an `untrusted` reference inside the `with` of a block hook (a node's `pre` or `post` hook, or a flow rule's) whose block is not `read` is the error `L3_TAINT_TO_CONSEQUENTIAL` on the hooked node, at the path of the reference, with the message `untrusted data from <from> reaches hook <hook> on <node> through <ref>, a block with side effects; pass it through an llm.extract node first`, where `<from>` is the node that produced the data (the hooked node for `hook.input.*`) and `<hook>` is the hook's `id`, or `rule.<rule id>` for a rule hook without one, or `(unnamed)` when that name does not match `^(rule\.)?[a-z][a-z0-9_]{0,63}$`; a code hook's `input`, a read block hook, `extracted` data and an unknown hook block give no such error.

#### Scenario: Code no longer launders
- **WHEN** `l3-taint-via-code` (a fetch, a `code` node over `nodes.fetch.output.content`, then `mail.send@1` with the code output as `body`) and `taint-extract-then-code-passes` (an `llm.extract` between the fetch and the code) are validated
- **THEN** the first has exactly one error, `L3_TAINT_TO_CONSEQUENTIAL`, node `send`, path `/nodes/send/with/body`; the second has no error and no warning

- **WHEN** `trifecta-all-three`, `trifecta-via-agent-tools`, `trifecta-absent-no-private`, `taint-to-opaque-delegate` and `taint-to-opaque-subflow` are validated, and `taint-via-extract-passes` is given, on its `extract` node, `pre: [{ id: h, kind: block, uses: "mail.send@1", with: { to: "a@example.com", subject: "s", body: "${{ nodes.fetch.output.content }}" } }]` (test-plan.md § Frozen case with a hook)
- **THEN** the first two give exactly the warning `W_LETHAL_TRIFECTA`, the third none, the next two exactly `W_TAINT_TO_OPAQUE_CALL`; the hooked flow has `ok: false`, `warnings` `[]`, `layers_run` `["L1", "L2", "L3"]` (the `H` layer does not run after an L3 error) and exactly one error, `{ layer: "L3", code: "L3_TAINT_TO_CONSEQUENTIAL", node: "extract", path: "/nodes/extract/pre/0/with/body", message: "untrusted data from fetch reaches hook h on extract through nodes.fetch.output.content, a block with side effects; pass it through an llm.extract node first" }`
