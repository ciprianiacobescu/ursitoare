The predicate shared by visit.ts and the block runtime requires error instanceof Error in addition to a recognised code, so a code-bearing copy that is not an Error instance falls to the fallback and becomes INTERPRETER_TOOL_FAILED with the fixed message, losing its code, node and details in the failed row and the run error. The repository does not state the shape of DBOS's replayed step error, which is exactly why the design chose a code-only rule.
