## MODIFIED Requirements

### Requirement: Mocks are checked against the flow before a run exists
`checkMocks` SHALL accept mocks only when each block node reachable from `start` (through its successors and the routes of its hooks) and each block hook placed on such a node (under `hookMockKey(nodeId, placement)`) has at least one entry and every entry is well formed and, for an `output`, valid against the block's output schema (a hook's against its hook block's), and SHALL otherwise answer the sorted list of problems; a key that is neither a node id nor the key of a block hook is `unknown_node`.

#### Scenario: Valid mocks pass and are copied
- **WHEN** `checkMocks(FLOW, payOnceCatalogue(), MOCKS)` runs; then with `FLOW` plus an unreachable block node `orphan` (`uses` `erp.flag_vendor@1`, `with` `{ vendor_id: "v1", reason: "r" }`, `next` `done`) once with `MOCKS` and once with `MOCKS` plus `orphan: [{ output: { flag_id: "f1" } }]`; with `pay: [{ error: { code: "E_DOWN", message: "down" } }, { output: PAID }]`; and with `emptyCatalogue` and `{ lookup: [{ output: 5 }], pay: [{ output: 6 }] }`
- **THEN** every call returns `problems: []` and `mocks` deep-equal to the input but a different object (setting `result.mocks.lookup[0].output.status` to `"x"` leaves the input unchanged); the last passes because a block the catalogue lacks is not schema-checked, and `route`, `done` and `rejected` need no mock

#### Scenario: Each problem reason, ordering and the cap
- **WHEN** `checkMocks(FLOW, payOnceCatalogue(), m)` runs for `m` equal to, each alone: `{}`; `{ lookup: [], pay: [{ output: PAID }] }`; `JSON.parse('{"lookup":[{"output":{"vendor_id":"v1","status":"active"}}],"pay":[{"output":{"payment_id":"pay-1","status":"paid"}}],"ghost":[],"route":[],"__proto__":[]}')`; `{ lookup: [{ output: { status: "active" } }], pay: [{ output: PAID }] }`; `{ lookup: "x", pay: [{ output: PAID, error: { code: "E", message: "m" } }, { error: { code: "bad code", message: "m" } }, 5] }`; `[]`; `null`; `lookup` holding 51 entries `{ output: {} }` with a valid `pay`; and, with `emptyCatalogue` (the block is unknown there), `{ lookup: [{ output: () => 1 }, { output: undefined }, { output: new Date(0) }, { output: CYCLE }, { output: NaN }, { output: { n: 1 } }], pay: [{ output: PAID }] }` where `CYCLE` is an object whose property `self` is itself
- **THEN** `mocks` is `null` each time and the problems, as `nodeId index reason`, ordered by `nodeId` (UTF-16 order) then `index` (`null` first), are: `lookup null missing`, `pay null missing`; `lookup null missing`; `__proto__ null unknown_node`, `ghost null unknown_node`, `route null not_a_block`; `lookup 0 schema` with `detail` `/ required` (and no `active` in it); `lookup null shape`, `pay 0 shape`, `pay 1 shape`, `pay 2 shape`; one `"" null shape` for `[]` and for `null`; exactly 50 problems `lookup 0 schema` to `lookup 49 schema`; and, for the last case, `mocks` `null` and the five problems `lookup 0 shape` to `lookup 4 shape`, each with `detail` `output is not JSON` (the plain object at index 5 is accepted, and nothing throws)

#### Scenario: Block hooks need mocks under their hook key
- **WHEN** `checkMocks(HOOKED, payOnceCatalogue(), m)` runs (`HOOKED`: `pay-once` with the rule `audit`, a pre block hook `invoices.get@1` on `lookup`, and on `pay` the post hooks `notify` (block, `slack.post_message@1`) and `tag` (code)); `FULL` is `{ lookup: [{ output: LOOKUP }], pay: [{ output: PAID }], "lookup:pre:rule.audit": [{ output: { invoice_id: "inv-1", raw_text: "t" } }], "pay:post:notify": [{ output: { ts: "1.0" } }] }`; `m` is `FULL`; `{ lookup, pay }`; `FULL` with `pay:post:notify` set to `[]`, to `[{ output: { ts: 5 } }]`, to `"x"`, to an error entry then `{ output: { ts: "1.0" } }`; `FULL` plus `"pay:post:tag"` and plus `"pay:post:ghost"`; `FULL` parsed from JSON with the extra own key `__proto__` set to `[]`; `FULL` on `HOOKED` plus an unreachable block node `orphan` that has a post block hook `n2` (`slack.post_message@1`), once as it is and once with `"orphan:post:n2": [{ output: { ts: 5 } }]`; and `FULL` on `HOOKED` plus a read block node `review` that only a code hook `to_review` (`routes: ["review"]`) on `pay` reaches
- **THEN** `FULL` gives `problems: []` and `mocks` deep-equal to it; `{ lookup, pay }` gives `lookup:pre:rule.audit null missing` and `pay:post:notify null missing` (sorted by key); `[]` gives `pay:post:notify null missing`; the schema case `pay:post:notify 0 schema` with `detail` `/ts type`; `"x"` `pay:post:notify null shape`; the error entry list is accepted; `pay:post:tag null unknown_node` and `pay:post:ghost null unknown_node` (a code hook has no mock key); `__proto__ null unknown_node`; `orphan` needs no mock (`problems: []`) and its bad mock is `orphan:post:n2 0 schema`; the routed `review` gives `review null missing`

### Requirement: The mock invoker answers from the mocks and nothing else
`createMockInvoker` SHALL answer the entry at index `ctx.attempt - 1` of the node's list as a fresh copy, or for a call with both `phase` and `hookId` of the list under `${nodeId}:${phase}:${hookId}` and never the node's own, and fail with `INTERPRETER_TOOL_FAILED` (a hook call adding `details.hook`, that key) for an error entry, a missing node or key or an exhausted list; `testRunInvokers` SHALL give an invoker over the mocks stored with the run in mode `mock` and refuse every other mode with `INTERPRETER_NO_INVOKER`.

#### Scenario: Entries by attempt, errors and no egress
- **WHEN** `createMockInvoker({ lookup: [{ output: LOOKUP_OK }], pay: [{ error: { code: "E_DOWN", message: "secret-text" } }, { output: PAID }] })` is invoked with `globalThis.fetch` replaced by a recorder: `lookup` twice (the first result mutated), `pay` with `attempt` 1, 2 and 3, and node `ghost`
- **THEN** both `lookup` calls resolve `{ output: LOOKUP_OK }`; `pay` attempt 1 rejects `InterpreterError` `INTERPRETER_TOOL_FAILED` with `node` `pay`, `details` `{ reason: "mock_error", mockCode: "E_DOWN" }` and a message without `secret-text`; attempt 2 resolves `{ output: PAID }`; attempt 3 rejects with `details.reason` `mock_exhausted`; `ghost` rejects with `details.reason` `mock_missing`; the recorder saw no call

#### Scenario: Mocks come from the stored run, in mock mode only
- **WHEN** on `createMemoryRunStore()` tenant A holds `r_1` (mode `mock`, mocks `MOCKS`) and `r_2` (mocks `null`), and `f = testRunInvokers(store)`: `f("mock", r_1)` is invoked for `lookup` and for `pay` (attempt 1) with tenant A; `f("live", r_1)` and `f("stub", r_1)` are awaited; `f("mock", r_2)` is invoked for `lookup` with tenant A, and `f("mock", r_1)` for `lookup` with tenant B
- **THEN** the first two invocations resolve `{ output: LOOKUP_OK }` and `{ output: PAID }`; the `live` and `stub` calls reject `INTERPRETER_NO_INVOKER`; the last two invocations reject `INTERPRETER_TOOL_FAILED` with `details.reason` `mocks_unavailable`

#### Scenario: A hook call is answered under its hook key
- **WHEN** `createMockInvoker({ lookup: [{ output: LOOKUP_OK }], pay: [{ output: PAID }], "pay:post:notify": [{ error: { code: "E_DOWN", message: "secret-text" } }, { output: { ts: "1.0" } }] })` is invoked with `globalThis.fetch` replaced by a recorder: the call `{ tool: "slack.post_message@1", args: {}, nodeId: "pay", effectSeq: 1, phase: "post", hookId: "notify" }` with `attempt` 1, 2 and 3; the call `{ …, nodeId: "pay", effectSeq: 2, phase: "pre", hookId: "audit" }`; the node call `{ tool: "erp.create_payment@1", args: {}, nodeId: "pay", effectSeq: 0 }`; and that node call with only `phase: "post"`
- **THEN** attempt 1 rejects `INTERPRETER_TOOL_FAILED` (node `pay`, `details` `{ reason: "mock_error", hook: "pay:post:notify", mockCode: "E_DOWN" }`, message without `secret-text`); attempt 2 resolves `{ output: { ts: "1.0" } }`; attempt 3 rejects with `{ reason: "mock_exhausted", hook: "pay:post:notify" }`; the `audit` call with `{ reason: "mock_missing", hook: "pay:pre:audit" }`; both node calls resolve `{ output: PAID }`; the recorder saw no call
