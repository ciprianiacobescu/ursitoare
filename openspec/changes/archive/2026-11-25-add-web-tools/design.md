## Decisions

1. **Files** are those of proposal § What Changes. The page has no `navLabel` (routes are not gated by capability); a link on "Tool servers" leads to it.
2. **The servers parser needs no change.** The card says `parseToolServer` fails a tool with `call` and no `http`; on main it does not: `parseHttp(undefined)` is `null` and unknown members are ignored (`servers.ts:70-76`, `:103-128`), and servers of all four adapters list on one page. A new view member would break the frozen `servers.test.ts` deep-equal (lesson z), and U56b reads the raw surface. So "A server whose tools carry a call is parsed and listed" pins what holds; the Call column stays "—" until U56b.
3. **Drafts validate only what the card names**; the engine decides the rest. Field names are the API's, so an answer's `fields` land on the form field. The `Idempotency-Key` is made at a draft's first submit and dropped by any edit. "Effect of <operationId>" is a plain `<select aria-label>`, not a kit `Field` (an operation id may hold `-` or `.`, which `isFieldName` refuses); the overlay holds the rows not set to "Skip".
4. **Credentials are write-only.** The secret is an uncontrolled `type="password"` input read once at submit into a local `const`, never in React state, and emptied when the call settles, by answer or error (a local refusal keeps it). Only the five members of `CredentialView` are read. Store sends a fresh `Idempotency-Key` per submit (U48 hashes the value into the request digest: a reused key with another value is 422); rotate has no key. The credential is found by paging `GET /credentials` (limit 200, at most 50 pages; U48 has no per-server read); without `manage_credentials` that is a 403 alert in the Credential section only. A code-block server (U55 refuses a credential) makes no request. Rotation sends the scheme and header name too (U55's rotate route takes them). A server that needs no key still needs a value: the form says so.
5. **No `messages.ts` edit**: `toolsErrorMessage` is pinned by M6 and `registerMessages` throws for one code with two texts (U56b could provoke it); `credentialErrors` owns 409, `no_credential_needed` and 503 `EGRESS_UNAVAILABLE`.
6. **Grants and D26.** Only the two `1024` of `grants.ts` become 128 (the message stays, so "A grant draft becomes the API body or names the field to fix" is not restated). Two frozen tests deep-equal `loadToolRefs`'s old result and change in place (task 2.1). `dryRunFormErrors` hands every non-400 error to `testRunFormErrors`, whose `refusedTest` gets one branch, `staleVersionText(details)`; no panel changes.
7. **Replace and edit (C10).** On the detail of an OpenAPI server a button "Replace document" opens the OpenAPI form; on a code-block server "Edit code" opens the code form pre-filled from the surface (the pending one, else the approved one; only a server with exactly one tool). Both save with `PUT /api/v1/tool-servers/<id>/openapi` (U53, stored origin) or `.../code` (U55). The document is not stored, so it is pasted again; `prefillEffects` gives a preview operation whose `name` is a surface tool's name that tool's effect. Deleting a server and moving an MCP URL are out of scope (carried).
8. **M6b base** (merged; shapes and lines in `delivered-shapes.md`). `RegisterPage.tsx`'s root is `cn("tools-page", PAGE_WIDTHS.form)` over one `<Card` as `PoliciesPage.tsx:104`, `:122`; the link is `Button asChild` around `Link` in the `actions` of `ServersPage.tsx`'s one `PageHeader` (`:215`); the new sections follow `:294`; the grant-form note follows `GrantsPage.tsx:323` and has no `tools-feedback`; the three buttons are kit `Button`s. No field is `required` (the kit appends " (required)" to its label). No `.tsx` imports CSS or holds a palette utility, hex or colour function (`ui/rules-tree.test.ts:44-56`); no CSS file is edited. `ServersPage.tsx` keeps the pins of `tools-pages-restyle.test.ts:33-99`: the new sections are separate files. No new link or button is named like a nav label or contains "Ursitoare". The stale text needs no JSX (`TestRunPanel.tsx:112`, `DryRunPanel.tsx:147`).

## Messages

**Drafts** (`field`: text; the first failing check in each function's order is returned). `id` (trimmed): not `^[a-z][a-z0-9_]{0,31}$` ID = "Enter a server id: lowercase letters, digits and underscores, starting with a letter, up to 32 characters." `url` (trimmed, WHATWG parse): blank or unparsable URL_T = "Enter a full URL, such as https://mcp.example.com/mcp."; not `https:` (nor `http:` with `local`) SCHEME = 'Use https, or tick "Local network server" for an http address.'; the body sends the trimmed text. `origin`: blank or unparsable ORIGIN_T = "Enter a full origin, such as https://tools.example.com."; SCHEME; the body sends `new URL(text).origin`. `document`, `input`, `output`: blank, bad JSON or not an object DOC_T = "Paste the OpenAPI document as a JSON object." (`input`: "Enter the input schema as a JSON object.", `output` likewise). no effect chosen: `document` "Choose an effect for at least one operation." Orders: `mcpRegistration` `id`, `url`; `previewRequest` `origin`, `document`; `openApiRegistration` `id`, `origin`, `document`, overlay; `codeRegistration` `id`, `input`, `output` (a blank `description` is left out, else it is trimmed and sent); the replacement builders check the same, except the id, which must match the server pattern (`RangeError`).

**Answers.** `registrationFormErrors`: a 409 `ALREADY_EXISTS` is `id` "A tool server with this id already exists."; a 413 `PAYLOAD_TOO_LARGE` is `document` "The document is over 1 MiB. Remove the paths you do not need, then preview again."; a 400 `VALIDATION_FAILED` puts each field on the form field it names (`body/tools/<i>/<k>` on `<k>`, `body/document/…` on `document`) when the kind has it (mcp `id`, `url`; openapi `id`, `origin`, `document`; code `id`, `name`, `description`, `input`, `output`, `source`), the others in the form text of `mapEnvelopeErrors`; any other error is `toolsErrorMessage`. A field message that is a key of `REGISTER_REASONS` (a constant of `register.ts`) reads as its sentence; an unknown reason keeps the engine's word. `REGISTER_REASONS`: `path` "Remove the query, fragment or text after the path."; `query` "Remove the query; store a key as a credential."; `credentials` "Remove the user name and password; store the key as a credential."; `loopback`, `localhost` "This address is the engine itself; use the server's network address."; `private`, `link_local` 'Tick "Local network server" for a private address.'; `metadata`, `service_name` "This address is reserved."; `server_mismatch` "The document's `servers` URL must be this origin or a path."; `openapi_version` "Only OpenAPI 3.0 and 3.1 JSON documents are supported."; `operation_excluded` "This operation cannot become a tool (see the Effect column)."; `name_collision` "Two operations get the same tool name; skip one."; `size` "The tools are too large; skip the operations you do not need."

**Parsing.** `parsePreview`: `name` null or a string; `version` `3.0` or `3.1`; `basePath` `""` or a string starting with `/`; each operation a record with `operationId` null or a non-empty string, `method` one of `GET POST PUT PATCH DELETE HEAD OPTIONS TRACE`, `path` a string starting with `/`, `excluded` null or a word of U53's `OpenApiExclusion`. `parseCredential`: `id` `^[A-Za-z0-9_-]{1,128}$`, `toolServerId` `^[a-z][a-z0-9_]{0,31}$`, `authScheme` one of the two schemes, `headerName` null or `^[A-Za-z0-9-]{1,64}$`, `keyVersion` an integer from 1 to 2147483647.

**Credentials.** `headerName` (trimmed, API key only): blank or not `^[A-Za-z0-9-]{1,64}$` HDR_T = "Enter a header name of 1 to 64 letters, digits and hyphens."; one of the 11 reserved names (`checkProvision`), any case, "That header name is reserved." `value` (not trimmed): empty, over 4,096 or a character outside `\x21-\x7e` VAL_T = "Enter the secret value: 1 to 4096 printable ASCII characters, no spaces." No message holds the value. `rotateServerCredential` checks its draft as `credentialBody` does and sends `{ value, authScheme }` and, for an API key, `headerName`. `credentialErrors`: 409 "A credential is already stored for this server."; 422 `no_credential_needed` "Code blocks need no credential."; 503 `EGRESS_UNAVAILABLE` "The credential vault is unavailable. Try again in a moment."; 400 fields on `headerName` and `value`; else `toolsErrorMessage`. `credentialText`: "No credential stored." | "Credential stored (key version N)." | "Code blocks need no credential." (a code-block server, whatever is given). `staleVersionText`: "This version was validated by an older validator. Validate it again from the flow's version page, then run it."

**Names.** `REGISTER_NAMES` holds exactly these 29 values, each under a camelCase key: "Register a tool server", "New tool server", "Kind", "MCP server", "OpenAPI document", "Code block", "Server id", "MCP URL", "Origin", "Local network server", "OpenAPI document (JSON)", "Preview operations", "Operations", "Skip", "Effect of ", "Tool name", "Description", "Input schema (JSON)", "Output schema (JSON)", "Source", "Register server", "Change registration", "Replace document", "Edit code", "Save changes", "Document replaced.", "Code saved.", "Do not paste a URL that holds a key; store the key as a credential.", "This server has several tools; edit it through the API.". `CREDENTIAL_NAMES` holds these 11 distinct values: "Credential", "Scheme", "API key header", "Bearer token", "Header name", "Secret value", "Store credential", "Rotate credential", "Credential stored.", "Credential rotated.", "A server that needs no key still needs a value here: enter any text.".

## Roles and names

**Register a tool server** (`/admin/tool-servers/new`): `h1` (`PageHeader`); form "New tool server" in a `Card` with the group "Kind" (radios "MCP server" default, "OpenAPI document", "Code block"), the field "Server id" and the fields of the kind (MCP URL carries the hint of `REGISTER_NAMES`; code: "Tool name", "Description" (optional), "Input schema (JSON)", "Output schema (JSON)", "Source"); `button type="button"` "Preview operations" (`aria-disabled` and inert while a preview or registration runs); the table "Operations" (columns "Operation", "Method", "Path", "Effect"; a row with `excluded` shows "Excluded: <reason>" in Effect and a null id "—"; the others have the combobox "Effect of <operationId>", options "Skip" with value "", "read", "write", "send", "pay"); submit "Register server". **Tool servers**, `?server=<id>`: a link "Register a tool server" in the page header; after the region "Surface" a `Section` "Credential": `LoadingState` or `ErrorPanel`, `p` `credentialText`, form "Credential" (radios "API key header" and "Bearer token", the field "Header name" for an API key (empty with bearer selected while none is stored, else pre-filled from the stored credential); field "Secret value", `type="password"`, located by label; submit "Store credential" or "Rotate credential"), the "enter any text" sentence while none is stored, `p role="status"` "Credential stored." or "Credential rotated."; a code-block server shows the `p` only; then, for an OpenAPI or code-block server, a `Section` "Change registration" with the button "Replace document" or "Edit code" that opens the form of that name (the register fields without "Server id", `LoadingState` "Loading code" while the draft loads, the text of `REGISTER_NAMES` for a server with several tools; for an OpenAPI server "Preview operations" fills the effects by `prefillEffects`; submit "Save changes"), then `p role="status"` "Document replaced." or "Code saved.". **Grants**: a `p` with `toolListNote(list)` under the select "Tool" when it is not null.
