# Test plan: the Node journey (constants, flows and fixtures: `test-plan.md` § Flows and journey constants)

## Node journey (`carol registers three servers and alice dry-runs through all three adapters`)

The web logic on the real engine; `fake`, `tools`, `mcp` are the `egressApi`, `toolsApi` and `mcpApi` fakes, `mcp` set with `mcp.setTools([...FAKE_MCP_TOOLS, HDR])`. No record, result or message holds a secret.

1. **MCP.** carol `registerServer` (`mcpRegistration` `crm`, `https://mcp.fake.test/mcp`), `storeCredential` (bearer, `e2e-crm-key`); `crmSvc` is the `serviceId` of the `crm` item of `GET /credentials`. `discoverTools(carol, "crm", discoverBody(initialDraft([])), "k-d1")` (no approved surface) resolves `{ protocolVersion: "2026-07-28", era: "modern", count: 2, excluded: [{ name: "route_ticket", reason: "x_mcp_header" }] }` (R4). `loadServerReview`: `state` `pending`, `approved` null, `changesView(approved, pending)` items `added find_vendor` and `added log_note`, each with the line `Description: (none)` (the fake lists no description); `parseReviewTools(pending)` gives `find_vendor|write|true|true|mcp find_vendor (2026-07-28)|read-only` and `log_note|write|true|true|…|not read-only, idempotent` (R3: `readOnlyHint` set nothing). A second `discoverTools` with `discoverBody({ effects: { find_vendor: "read", log_note: "" } })` (`k-d2`) makes `find_vendor` `read`, still `true|true`.
2. **Discovery on the wire.** `mcp.requests()` holds four entries, methods `server/discover`, `tools/list`, `server/discover`, `tools/list`, each `era` `modern`, `host` `mcp.fake.test`, `path` `/mcp`, `status` 200, `headers.authorization` `[credential]`, `callHeader` `^disc_[0-9a-f-]{36}:crm:[12]$`; the first and third `bodySha256` are `W3`. `GET /policy-decisions?action=register_tool_server&order=asc&limit=200`: the four items with a `permit` are `allow`, `reasons` containing `tools-register-admin`, permits `{ method: "POST", host: "mcp.fake.test", path: "/mcp", serviceId: crmSvc, ttlSeconds: 60 }` with `bodyDigest` equal to the `bodySha256` at that position. `fake.issued()` holds four tokens of `crmSvc` (TTL 60), `fake.requests()` four `allowed` requests.
3. **OpenAPI and code.** `previewOperations` (`previewRequest`, `https://tools.fake.test`, `DOC`) gives two operations, `excluded` null; `registerServer` (`openApiRegistration` `ledger`, effects `createPayment` `pay`, `lookupVendor` `read`) and `storeCredential` (API key header `x-fake-tools-key`, `e2e-ledger-key`), whose result is `authScheme` `API_KEY_HEADER`, `headerName` `x-fake-tools-key`, `keyVersion` 1 (`pay` is authorised with a permit even when stubbed, so a missing credential would fail only at the dry run). `parseReviewTools(pending)`: `create_payment|pay|true|true|POST /blocks/erp.create_payment@1|—` (U53's default for every effect but `read`), `lookup_vendor|read|true|false|POST /blocks/erp.lookup_vendor@1|—`. `registerServer` (`codeRegistration` `calc`, `risk_score`, `CALC_IN`, `CALC_OUT`, `SRC`): `risk_score|read|false|false|code (54 characters)|—`.
4. **Approve, flow, grants.** carol `approveToolSurface(..., { digest, selfApproval: true })` for `crm` (refs `crm.find_vendor@1`, `crm.log_note@1`), `ledger` and `calc`; alice `postFlow` (`demo-live`, `finance`), `saveVersion`, `validateVersion` (`ok` true, `errors` `[]`, warning codes `["W_LETHAL_TRIFECTA"]`); carol `postGrant` (role `author`, any step) for `crm.find_vendor@1`, `calc.risk_score@1`, `ledger.lookup_vendor@1`, `ledger.create_payment@1`, `deployPolicy`; then `fake.clearRecords()`, `tools.reset()`, `mcp.reset()`.
5. **The dry run.** alice `startDryRun(..., "demo-live", hash, INPUT, FAKES, "k-1")`, `followRun`: `completed`, `terminalNode` `done`; steps `find`, `score`, `vendor`, `pay`, `done` `completed`, `taint` `[]` except `["untrusted"]` for `done`; `idemKey` null for the reads, `^ik1_[0-9a-f]{64}$` for `pay`; outputs `find` `{ vendor_id: "V-ACME", status: "active" }`, `score` `{ band: "low" }`, `vendor` `{ vendor_id: "V-ACME", status: "active", payment_terms_days: 30 }`, `pay` `{ payment_id: "P-7", status: "created" }`; `decisionRows` texts `find · allow · POST mcp.fake.test/mcp`, `score · allow`, `vendor · allow · POST tools.fake.test/blocks/erp.lookup_vendor@1`, `pay · allow · stubbed · POST tools.fake.test/blocks/erp.create_payment@1`.
6. **Each adapter live.** MCP: `mcp.requests()` holds one entry, `tools/call`, `toolName` `find_vendor`, `callHeader` `<run>:find:1`, `bodySha256` `W1` and equal to `find`'s permit `bodyDigest` in `GET /runs/<run>/decisions`. HTTP: `tools.calls()` holds one call, `erp.lookup_vendor@1`, `POST`, `callHeader` `<run>:vendor:1`, `keyHeaderSeen` true, `input` `{ vendor_name: "Acme GmbH" }`, `status` 200, `bodySha256` equal to `vendor`'s `bodyDigest`; `tools.calls({ ref: "erp.create_payment@1" })` is `[]`. Code: `score`'s `permit` is `null`. Broker: two tokens (`crmSvc`, then the `ledger` service; TTL 60) and two `allowed` forwarded requests (`mcp.fake.test` `/mcp`; `tools.fake.test` `/blocks/erp.lookup_vendor@1`), none for `score` or `pay`.
