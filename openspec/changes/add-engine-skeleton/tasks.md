## 1. Core

- [ ] 1.1 Write `src/core/clock.test.ts` and `src/core/ids.test.ts` first, then implement `Clock`, `systemClock`, `fixedClock`, `IdSource`, `createIds` (counter-based UUIDv7 with `node:crypto`), `systemIds` and `sequentialIds` in `src/core/clock.ts` and `src/core/ids.ts`, and the `LogLevel` type in `src/core/index.ts`, implementing requirement "Injected clock and time-sortable ids". `createIds` writes 48-bit unix ms (12 hex), version 7, a 12-bit counter in `rand_a`, variant `10` and the rest from `randomBytes(8)` (default `node:crypto`): `(b[0] & 0x3f | 0x80)`, `b[1]`, then `b[2..7]`. State `{ lastMs: -1, counter }`, `ms = clock.now().getTime()`: if `ms > lastMs` then `lastMs = ms`, `counter = 0`, else `counter += 1`, and past `0xfff` `lastMs += 1`, `counter = 0`; `lastMs` is written. The prefix matches `^[a-z][a-z0-9]{0,15}$`. `sequentialIds(seed = 0)` returns `${prefix}_00000000-0000-7000-8000-<counter, 12 hex>`, first counter `seed` (integer 0 to `0xffffffffffff`, else `RangeError`, also on overflow)
