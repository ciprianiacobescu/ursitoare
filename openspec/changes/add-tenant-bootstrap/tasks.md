Tests follow `test-plan.md`. Every test file starts with `assert.equal(typeof <the name it tests>, "function")`, wraps every stub call so a throwing stub fails by assertion, reads an error's `code` as `(e as { code?: unknown }).code`, cleans up in `finally`, and has no `.`, `[` or `::` in a test name. Red tests import each name from the file its header in `design.md` § Interfaces names, never from an `index.ts`. The image run of the chain is the delegate's (`test-plan.md` § STACK-ONLY).
