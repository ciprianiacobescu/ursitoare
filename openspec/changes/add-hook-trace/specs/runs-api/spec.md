## MODIFIED Requirements

### Requirement: Run and step views expose the stored rows
`toRunView` and `toStepView` SHALL map a `RunRecord` and a `StepRecord` field by field into `RunView` and `StepView`, leaving out the internal columns, `toStepView` SHALL also copy the record's `hooks` when it has one and add no key otherwise, and `RUN_VIEW_SCHEMA` and `STEP_VIEW_SCHEMA` SHALL list exactly the view fields, the step schema listing `hooks` in `properties` after the fifteen fields but not in `required`.

#### Scenario: Views, schemas and the policy resource
- **WHEN** `toRunView` gets the record `{ runId: "run-4", lineageId: "run-4", parentRunId: null, flowId: "rf-2-ap", flowHash: "sha256:" + "a".repeat(64), ownerTeam: "finance", mode: "mock", trigger: "test", state: "failed", principal: { userId: "u_erin", kind: "human" }, actorChain: ["u_erin"], inputRef: "b".repeat(64), mocksRef: "c".repeat(64), outputRef: null, error: { code: "FLOW_FAILED", message: "flow ended failed", node: "rejected" }, terminalNode: "rejected", runDay: "2026-11-02", createdAt: "2026-11-02T09:00:04.000000Z", startedAt: "2026-11-02T09:00:05.000000Z", endedAt: "2026-11-02T09:00:06.000000Z" }`; `toStepView` gets `{ runId: "run-4", nodeId: "pay", effectSeq: 1, turn: 2, attempt: 3, generation: 4, seq: 7, kind: "block", state: "completed", inputRef: "a".repeat(64), outputRef: null, outcome: "ok", error: null, taint: ["untrusted", "private"], policyDecisionId: "dec_1", idemKey: "ik1_x", startedAt: "2026-11-02T09:00:05.000000Z", endedAt: null }`; the two schemas are read; `toStepView` also gets that record with `hooks` `{ inputOriginalRef: "d".repeat(64), entries: [{ label: "post:rule.rule_a", kind: "code", fused: false, attempt: 1, state: "completed", action: "continue", mutated: null, to: null, error: null, tool: null, idemKey: null }] }`; `runResource("tenant_a", record)` is called
