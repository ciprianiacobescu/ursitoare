## Why
The verifier found problems in `add-web-tool-trust` that this change fixes. The findings are listed below with their ids; each task of this change names the ones it answers.

## What Changes

The 100-key test row uses keys in effects only, so no test pins the gap. - F-1b3e37fc (major): Page trust lookups read inherited Object.prototype members instead of Object.prototype-safe defaults: Decided by delegate in Q-009: The finding is correct. The design requires every lookup by a tool name or operationId to use Object.hasOwn or a Map, and the builders do, but the three pages read the trust record with a plain index and a nullish fallback.
