# Browser tests with mocked API answers

`e2e/test_m7_tool_registration.py`: four tests, each `@pytest.mark.milestone("M7")` and `@pytest.mark.l4("C-…")` with the id L4 derives for the scenario named at it. Fixtures `page` only (no `fresh_state`, no `login`: `e2e/test_m6b_admin.py:1`, `:101-106`); `from conftest import assert_accessible, assert_layout, watch_csp`. Every test: `csp = watch_csp(page)` before its first `goto`, `page.set_viewport_size({"width": 1366, "height": 860})`, the mocks, then `goto`; after each view (each `goto`, `reload()`, navigation) it first `expect`s content only that view renders, then calls `assert_layout(page)` and `assert_accessible(page)`; it ends with `assert csp == []`. It copies `CSRF`, `ME` and `CAROL` of `e2e/test_m6b_admin.py:12-25`, with `ME["capabilities"]` set to `["register_tool_server", "manage_credentials"]` (the shapes `parseMe` and `parsePeople` read, `delivered-shapes.md`), and answers `answer(page, "me", (200, ME))` and `answer(page, "people", (200, CAROL))`: only the detail's "Registered by" asks `/people` (unmocked: the user id shows, nothing alerts), and no page here asks `/api/v1/me/teams` (`flows/FlowsPage.tsx:45` does). Every locator names role and name with `exact=True`, `get_by_label` too ("OpenAPI document" is a radio beside the textbox "OpenAPI document (JSON)"); a row count by role `row` includes the header row. A kit `Field` error is `<p class="ui-field-error"><span class="ui-visually-hidden">Error: </span>T</p>` (`web/src/kit/data/Field.tsx:29-34`): "under X the text T" means `expect(page.get_by_label("X", exact=True)).to_have_accessible_description(re.compile(re.escape(T)))`, and "`form` shows T" means `to_contain_text(T)` on the form (`get_by_text(T)` finds nothing). A `len(hits)` or any list read follows an `expect` on text only that reply renders, never `goto` or `reload()`. The file copies `answer(page, path, *replies, method="GET")` (hit n gets reply n, the last repeats; `hits` hold `headers` and `body`), `HOLD`, `INTERNAL`, `_request_body` and `_header(hit, name)` (case-insensitive) of `e2e/test_m6_tool_pages.py`. `IO` is `{"type": "object"}`. `EMPTY` is `(200, {"items": [], "next_cursor": None})`; `fields(f, m)` is `(400, {"error": {"code": "VALIDATION_FAILED", "message": "m", "details": {"fields": [{"field": f, "message": m}]}}})`; `CONFLICT` is `(409, {"error": {"code": "ALREADY_EXISTS", "message": "m"}})`; `region(n)` is `page.get_by_role("region", name=n, exact=True)`. `REC(id, adapter, origin, **over)` is the server record `{"id": id, "adapter": adapter, "origin": origin, "state": "pending", "registeredBy": "u_carol", "approvedDigest": None, "pendingDigest": None, "pendingSubmittedBy": None, "tools": [], **over}`; `DETAIL(r)` adds `"approvedSurface": None, "pendingSurface": None`; `CRM` is `REC("crm", "mcp", "https://mcp.fake.test")`.
