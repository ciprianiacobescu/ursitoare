# Browser tests (mocked answers, no sign-in)

`e2e/test_m6b_kit.py`, three tests, each with `@pytest.mark.milestone("M6b")` and `@pytest.mark.l4("C-…")`. Fixtures `page` and `base_url` only (no `fresh_state`, no `login`); imports `from conftest import assert_accessible, assert_layout, watch_csp`. Locators by role with `exact=True`, no sleep. Each test sets the viewport to 1366 by 860 and calls `watch_csp(page)` before the first `goto`. The banner is U07b's (97 px alice, 265 px carol today), so `assert_layout` runs with `max_banner_px=300`.

**Mocks** (a `page.route` on the regex `/api/v1<path>(\?.*)?$`, status 200, `application/json`):
