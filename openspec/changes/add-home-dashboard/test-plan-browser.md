# Browser tests (mocked API answers, no sign-in, no fixtures from the stack)

`e2e/test_m6b_home.py`: four test functions, each with `@pytest.mark.milestone("M6b")` and `@pytest.mark.l4("C-…")`. Each sets 1366 by 860 first. They use the `page` fixture and `from conftest import assert_accessible, assert_layout, watch_csp`; locators are by role and name with `exact=True`; no sleep. The engine's own `/health` answers; nothing signs in.

Helpers inside the file:
- `at(seconds_ago)`: the ISO instant `NOW - seconds_ago`, six fraction digits, `Z`. A function `fixtures()` reads `NOW` and builds `RUNS` and `FLOWS` inside each test, never at import: the suite collects every file first and reaches this one about two minutes later, when "3 min ago" would read "5 min ago". `run(...)`, `version(...)` and `flow(...)` build the 15-key `RunView`, 10-key `VersionRow` and flow literals (principals `user-1`, the mocked person, and `user-2`; `HASH` as in test-plan.md).
- `mock_me(page, name, caps)` routes `.*/api/v1/me$` to 200 `{"user": {"id": "user-1", "displayName": name, "email": null}, "tenant": {"id": "tenant-1", "name": "E2E tenant", "reviewProfile": "solo"}, "capabilities": caps, "csrfToken": "t" + "A" * 42}`; `answer(page, pattern, status, body)` does the same for any route; `words(locator)` is `" ".join(locator.inner_text().split())`.
- `ALICE` = `read_self`, `read_flow`, `read_run`, `read_registry`, `test_flow`, `dry_run_flow`; `CAROL` = the eleven of test-plan.md T4 ADMIN.
- `RUNS`: R1 `run_01a1eb72-3179-7000-a94d-6c6eaf5d03ac` demo-pay completed `user-1` (began 200 s ago, took 1.4 s); R2 `run_01a1eb70-0000-7000-8000-00000000be11` demo-grants failed `user-2` (7500 s ago, 75 s); R3 `run_01a1eb6f-0000-7000-8000-00000000cafe` demo-pay queued `user-2` (not started, created 90000 s ago). `FLOWS`: alpha-flow (created 400000 s ago, latest v1 draft `validationOk` false), demo-draft (300 s ago, no latest), demo-pay (90000 s ago, latest v2 validated true created 3700 s ago). `/api/v1/people` answers `{"items": [{"userId": "user-2", "displayName": "Bob Example", "kind": "human"}]}`. Each age leaves at least 39 s before its text changes.
