Tests follow `test-plan.md`. Every test file starts with `assert.equal(typeof <the name it tests>, "function")`, wraps every stub call so a throwing stub fails by assertion, closes pools, servers, fakes and stacks in `finally` or `t.after`, takes every time from an injected clock, and has no `.`, `[` or `::` in a test name. Red tests import each name from the file its header in `design.md` § Interfaces names, never from an `index.ts`. Red tests reach `AppConfig.auditSink` and `ACTIONS.emit_audit` through the AGENTS.md cast. The criteria of every task are gate-decided; the real broker and proxy delivering to the port is the delegate's stack run (`test-plan.md` § STACK-ONLY) and is in no task.
