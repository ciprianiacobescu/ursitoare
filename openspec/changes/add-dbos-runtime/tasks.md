Spec: `specs/durable-runtime/spec.md`; decisions: `design.md`; merged shapes: `delivered-shapes.md`. Every test file starts with `assert.equal(typeof <the function it tests>, "function")`; a call that reaches a scaffold stub is wrapped as `p.then((v) => v, (e: unknown) => e)` and asserted, so red fails by assertion. Errors are asserted by `code` and `details.reason`; test names have no `.`, `[` or `::`; a test that launches a runtime shuts it down in `finally`.
