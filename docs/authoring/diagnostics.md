# Flow diagnostics

Generated by `renderDiagnosticsDoc()` in `src/authoring/validate/diagnostics.ts`; do not edit by hand. Regenerate with `node -e "import('./src/authoring/validate/diagnostics.ts').then((m) => process.stdout.write(m.renderDiagnosticsDoc()))" > docs/authoring/diagnostics.md`.

Every flow diagnostic has a stable code. A validator issue carries its layer, code, node, JSON Pointer path and message; the table below gives what each code means and how to fix it.

### L1_PARSE

L1 error

The flow text could not be parsed.

Fix: Check the YAML or JSON syntax, and any unsupported tags or duplicate keys.

### L1_REQUIRED

L1 error

A field the schema requires is absent.

Fix: Add the missing field at the reported path.

### L1_ADDITIONAL_PROPERTY

L1 error

The document has a field the schema does not list.

Fix: Remove the field or move it into a node kind that supports it.

### L1_TYPE

L1 error

A value has the wrong JSON type.

Fix: Use the JSON type the schema declares.

### L1_CONST

L1 error

A fixed value differs from the value the format requires.

Fix: Set the field to the required constant.

### L1_ENUM

L1 error

A value is not one of its allowed values.

Fix: Use one of the listed values.

### L1_UNKNOWN_KIND

L1 error

A node kind is not one of the fourteen known kinds.

Fix: Use a known node kind.

### L1_PATTERN

L1 error

A string does not match its required pattern.

Fix: Correct the identifier, version, role or reference to the required form.

### L1_MIN_ITEMS

L1 error

A list has fewer entries than the schema allows.

Fix: Add at least the minimum number of entries.

### L1_UNIQUE_ITEMS

L1 error

A list repeats an entry.

Fix: Remove the duplicate entry.

### L1_RANGE

L1 error

A number is outside its allowed range.

Fix: Use a value inside the allowed range.

### L1_MIN_LENGTH

L1 error

A required text field is empty.

Fix: Fill in the empty field.

### L1_MIN_PROPERTIES

L1 error

An object or map is missing members the schema requires.

Fix: Add the required members.

### L1_FOREACH_BODY

L1 error

A foreach has both or neither of uses and subflow.

Fix: Keep exactly one of uses and subflow on the foreach.

### L1_INVALID_JSON_SCHEMA

L1 error

An embedded JSON Schema is not valid.

Fix: Make the schema a valid JSON Schema 2020-12 object.

### L1_REF_SYNTAX

L1 error

A reference in a value field is not well formed.

Fix: Write the reference as ${{ inputs.x }}, ${{ nodes.id.output.path }} or ${{ item.path }}.

### L1_REF_NOT_ALLOWED

L1 error

A reference appears where references are not allowed.

Fix: Remove the reference from instructions, goal or source.

### L1_CODE_SYNTAX

L1 error

The code node source does not parse as a function body.

Fix: Fix the JavaScript syntax in the code source.

### L1_CODE_NO_RETURN

L1 error

The code source has no return of its own.

Fix: Return a value from the top level of the code body.

### L2_UNKNOWN_BLOCK

L2 error

A block or agent tool is not in the catalogue.

Fix: Use a block the catalogue defines.

### L2_WITH_MISSING_REQUIRED

L2 error

A with object lacks an input the block or flow requires.

Fix: Provide every required input of the block or flow.

### L2_WITH_UNKNOWN_PARAM

L2 error

A with key is not an input of the block or flow.

Fix: Remove the key or use a declared input.

### L2_UNKNOWN_ROLE

L2 error

The assignee role is not in the catalogue.

Fix: Use a role the catalogue defines.

### L2_UNKNOWN_DELEGATE_TARGET

L2 error

A delegate target is not in the catalogue.

Fix: Use a delegate target the catalogue offers.

### L2_UNKNOWN_DELEGATE_WORKFLOW

L2 error

A delegate workflow is not offered by its target.

Fix: Use a workflow the target offers.

### L2_UNKNOWN_FLOW

L2 error

A subflow is not in the catalogue.

Fix: Use a flow name and major version the catalogue defines.

### L2_UNKNOWN_MODEL_PROFILE

L2 error

A model profile is not in the catalogue.

Fix: Use a model profile the catalogue defines.

### L2_START_UNKNOWN

L2 error

The start field names no node.

Fix: Point start at an existing node id.

### L2_UNKNOWN_SUCCESSOR

L2 error

A successor names no node.

Fix: Point the successor at an existing node id.

### L2_MISSING_SUCCESSOR

L2 error

A node lacks a successor its kind requires.

Fix: Add the successor field the node kind requires.

### L2_UNREACHABLE_NODE

L2 error

A node is not reachable from start.

Fix: Connect the node to a path from start or remove it.

### L2_CYCLE

L2 error

The graph has a cycle.

Fix: Break the cycle; flows must be acyclic.

### L2_NO_END

L2 error

The flow has no end node.

Fix: Add an end node.

### L2_DECIDE_CASE_MISSING

L2 error

An llm.decide outcome has no cases entry.

Fix: Add a cases entry for every outcome.

### L2_DECIDE_CASE_EXTRA

L2 error

A cases key is not an outcome.

Fix: Remove cases keys that are not outcomes.

### L3_REF_UNKNOWN_NODE

L3 error

A nodes reference names no node.

Fix: Reference an existing node id.

### L3_REF_NOT_DOMINATING

L3 error

The referenced node is not guaranteed to have run.

Fix: Reference only a node that runs on every path to the reader.

### L3_REF_UNKNOWN_PATH

L3 error

A reference path does not resolve in the schema.

Fix: Reference a property the output schema declares.

### L3_REF_NO_OUTPUT

L3 error

The referenced node produces no output.

Fix: Reference a node that produces output.

### L3_REF_OUTCOME_NOT_DECIDE

L3 error

An outcome is read from a node that is not llm.decide.

Fix: Use outcome only on an llm.decide node.

### L3_ITEM_OUTSIDE_FOREACH

L3 error

An item reference appears outside the with of a foreach.

Fix: Use item only in the with of a foreach.

### L3_TYPE_MISMATCH

L3 error

A value type does not match the consumer's schema.

Fix: Pass a value of the declared type or convert it first.

### L3_ENUM_VIOLATION

L3 error

A value is not one of the consumer's allowed values.

Fix: Pass a value from the consumer's enum.

### L3_SWITCH_ON_TYPE

L3 error

A switch cannot switch on an object or array.

Fix: Switch on a string, number or boolean value.

### L3_SWITCH_KEY_INCOMPATIBLE

L3 error

A switch case key cannot match the switch value.

Fix: Use a case key compatible with the value's type and enum.

### L3_TAINT_TO_CONSEQUENTIAL

L3 error

Untrusted data reaches a consequential block.

Fix: Pass untrusted data through llm.extract before the call.

### L3_TAINT_TO_AGENT_WITH_EFFECTS

L3 error

Untrusted data reaches an agent with effectful tools.

Fix: Pass untrusted data through llm.extract before the agent.

### W_LETHAL_TRIFECTA

L3 warning

The flow reads untrusted content, reads private data and can send or pay.

Fix: Remove one capability or isolate it behind a policy-checked step.

### W_TAINT_TO_OPAQUE_CALL

L3 warning

Untrusted data is passed to a subflow, delegate or foreach subflow.

Fix: Pass untrusted data through llm.extract before the opaque call.

### W_OPTIONAL_REFERENCE

L3 warning

A reference ends at a field its schema does not require.

Fix: Reference a required field or handle the missing value.

### W_SUSPICIOUS_INTERPOLATION

L1 warning

Plain text around a reference looks like a mistaken interpolation.

Fix: Use a ${{ }} reference for each dynamic value.

### W_CODE_FORBIDDEN_API

L1 warning

A code source uses an API the sandbox forbids.

Fix: Remove the forbidden API from the code source.

### INTERNAL_ERROR

reserved error

The validator crashed or a taint analysis limit was exceeded.

Fix: Report this as a validator bug; simplify the flow if a limit was exceeded.
